# Tests

`run-tests.sh` creates projects in a temporary directory and builds them with each project's `./build.sh`:

- every template from scratch;
- the demo paper with its own template (`ieee-conference`) and with every other template, each followed by the checks;
- `./build.sh check`, `./build.sh snapshot`, and the failure report for a deliberately broken build.

```bash
tests/run-tests.sh --setup   # first run: install the toolchain into tests/.cache, then test
tests/run-tests.sh           # later runs reuse tests/.cache (or tools on PATH)
```

The temporary directory is kept, and its path printed, only if a test fails.

CI (`.github/workflows/tests.yml`) runs `tests/run-tests.sh --setup` on Linux (x86_64, arm64) and macOS (Apple Silicon, Intel), caching the toolchain.

## Demo paper

`demo-paper/` is a project created with the `paper-init` skill (`ieee-conference` template) and filled in following the other skills. It exercises:

- citations with locators and multiple keys, imported by DOI and from arXiv (`references/references.bib`)
- pandoc-crossref references to sections, figures, tables, and equations
- Markdown tables converted by `latex/filters/tables.lua`, and a raw LaTeX table
- raw LaTeX `align` with a reference from Markdown
- figures generated by `figures/src/*.py` from `data/`
- the `drafts/` folder with `00-raw/` raw material stubs

All experimental data in the demo paper is synthetic, and the paper says so. The references are real and were fetched from DOI/arXiv metadata.

To build it directly: `cd tests/demo-paper && ./build.sh setup && ./build.sh`.
